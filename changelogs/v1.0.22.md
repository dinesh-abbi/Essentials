# Release Changelog v1.0.22

*Released on: Tuesday, 19 August 2026*

**Sleeker navigation, modernized dashboard & profile, smoother scrolling, smart updates, and widget fixes.**

### 🚀 New Features

- **Smart updates & zero redownloads** — If an update was already downloaded to your device, the app detects it immediately and offers a one-tap "Install Now" button without wasting data downloading the file again.
- **Automatic storage cleanup** — The app now automatically cleans up old update installation files from your device storage to keep your phone clean and save space.
- **Screen-aware install handling** — Updates now respect your phone's screen and lock state. If a download finishes while your screen is off or the app is in the background, you'll receive a helpful notification and can complete the installation as soon as you turn your screen back on.
- **Scroll-aware navigation** — The navigation bar now smoothly slides away as you scroll down through content, giving you more room to read. Scroll back up and it glides right back into view.

### 🎨 UI & UX Modernization

- **Revamped Profile screen** — Transformed the Profile into a clean, modern layout. Replaced long vertical lists with a 2x2 Bento grid for Discord integrations, Barcode Alarm, App Version, and Cloud Sync. Removed redundant user info and added an inline name editor right inside the profile card.
- **Compact & fluid Hydration hero** — Redesigned the Home screen water module with a balanced, modern layout featuring a fluid capsule vessel with spring physics, animated odometer numbers, and quick-tap log buttons.
- **Upgraded Spend & Check-in cards** — Elevated the secondary cards with dynamic budget indicator bars, animated camera viewfinder scanning lines, and quick action prompts for easy reviewing.
- **Spacious Record Expense form** — Rebuilt the expense entry layout with a dedicated currency input, spacious date and time pickers, and a wrap-around category chip cloud that eliminates horizontal gesture conflicts when swiping between tabs.
- **Compact navigation pill** — The bottom bar is now a slim, frosted-glass pill with crisp blur and comfortable bottom clearance across all screens.

### 🐛 Bug Fixes

- **Widget and app stay in sync** — Logging water from the home-screen widget now updates the app instantly upon opening, so both always reflect identical hydration totals.
- **Smooth tab bar reveal** — Fixed bottom bar jitter during scrolling by driving visibility worklets directly on the UI thread.
