# Release Changelog v1.0.22

*Released on: Tuesday, 19 August 2026*

**Sleeker navigation, smoother scrolling, and widget fixes.**

### 🚀 New Features

- **Redesigned navigation bar** — The floating bottom bar is now smaller and more compact, using an icon-only design that takes up less screen space. Inspired by the clean navigation style found in modern apps.
- **Scroll-aware navigation** — The navigation bar now smoothly slides away as you scroll down through content, giving you more room to read. Scroll back up and it glides right back into view — no more abrupt jumps or disappearing acts.

### 🐛 Bug Fixes

- **Widget and app now stay in sync** — Previously, logging water from the home screen widget would update the widget but the app would still show the old number when you opened it. Now the app instantly picks up any changes made from the widget, so both always show the same total.
- **Navigation bar no longer jumps off screen** — Fixed an issue where the bottom bar would snap away suddenly instead of sliding smoothly. The animation now tracks your finger movement naturally.

### 🎨 UI Improvements

- **Compact navigation pill** — The bottom bar is now a slim, frosted-glass pill that floats neatly at the bottom of the screen. It's 25% smaller than before while keeping the same easy-to-tap touch targets.
- **Smoother animations everywhere** — Navigation transitions, the active tab indicator, and press feedback all feel more fluid and responsive. Tapping a tab icon now gives a subtle, satisfying bounce.
- **Better blur effect** — The frosted glass look on the navigation bar is crisper and more visible, especially in dark mode where it no longer washes out to a flat grey.
