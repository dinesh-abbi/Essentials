# Release Changelog v1.0.23

*Released on: Tuesday, 19 August 2026*

**Modern Profile 2x2 Bento dashboard, fluid Hydration motion design, improved expense tracking, and background update intelligence.**

### 🚀 New Features

- **Smart updates & zero redownloads** — If an update was already downloaded to your device storage, the app detects it immediately and offers a one-tap "Install Now" button without wasting your data downloading the file again.
- **Screen-aware install handling** — Updates now respect your phone's lock state. If a download finishes while your screen is off, you'll receive a helpful notification to complete the installation as soon as you turn your screen back on.
- **Automatic storage cleanup** — The app automatically cleans up old update installation files from your device to keep your storage neat and free of clutter.
- **Scroll-aware navigation** — The floating bottom navigation bar smoothly slides away as you scroll down through content, giving you more reading space, and glides back into view when you scroll up.

### 🎨 UI & UX Modernization

- **Revamped Profile screen** — Redesigned the entire Profile screen with a modern, compact 2x2 Bento grid for Discord integrations, Barcode Alarm settings, App Version info, and Cloud Sync status. Eliminated repetitive list items and added an inline name editor directly into the top profile card.
- **Fluid Hydration hero card** — Upgraded the Home screen water module with a balanced layout featuring an animated fluid capsule with spring physics, real-time odometer count-up, and quick-tap log buttons.
- **Enhanced Spend & Check-in cards** — Rebuilt secondary cards with dynamic budget indicator bars, animated camera viewfinder scanning lines, and direct review shortcuts.
- **Spacious Record Expense form** — Redesigned the expense input layout with a dedicated currency input, spacious date and time pickers, and a wrap-around category chip grid that prevents accidental gesture conflicts with horizontal tab swiping.
- **Compact navigation pill** — The bottom navigation bar is now a slim frosted-glass pill with increased screen clearance so content never gets obscured.

### 🐛 Bug Fixes

- **Instant widget & app sync** — Logging water from your home-screen widget now updates the in-app hydration totals immediately upon opening.
- **Smooth tab bar reveal** — Fixed bottom navigation bar jitter during scrolling by driving visibility worklets directly on the UI thread.
