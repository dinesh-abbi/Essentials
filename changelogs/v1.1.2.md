# Release Changelog v1.1.2

*Released on: Saturday, 29 August 2026*

**A refined "Technical, but kind" redesign of Home and navigation, a livelier hydration hero, a cleaner floating nav bar, and a matching widget palette.**

### 🎨 UI & UX Modernization

- **Reworked hydration hero** — The Home screen's water vessel now has a genuine dual-wave surface (two independently-phased waves layered for a natural parallax ripple), floating bubbles that vanish precisely at the liquid line, and a spring-driven fill that reacts with real weight when you log or remove water.
- **AM/PM hourly activity dots** — A new two-row dot grid on the hydration card shows exactly which hours you've logged water today, at a glance.
- **Calmer secondary cards** — Spend and Check-in now sit in a shared bracket-labelled card shell with hand-drawn line illustrations, instead of mismatched one-off layouts.
- **Slimmer floating nav bar** — Rebuilt the bottom tab bar as a minimal hairline pill with a sliding active-tab indicator and a single accent colour reserved for the active icon, replacing the previous glass/blur experiment.
- **Staggered entrance animation, fixed for real** — Home screen elements now animate in with a genuine staggered delay between them; a previous build reported this as working but the stagger value was silently discarded, so every element animated in at once.

### 🐛 Bug Fixes

- **Home-screen widget re-themed to match the app** — The widget's colours were still on the old blue palette from a previous design pass and hadn't been updated when the app's palette changed, so it looked out of place next to the redesigned app. It now mirrors the app's current sage-green palette in both light and dark launcher themes.
- **Assorted fixes and improvements** across updates and other screens.

### 🧹 Cleanup

- Removed leftover files from an abandoned in-progress redesign experiment that never shipped.
