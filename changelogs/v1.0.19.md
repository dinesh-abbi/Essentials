# Release Changelog v1.0.19

*Released on: Tuesday, 12 August 2026*

### 🚀 New Features
- **Widget Quick-Log Headless Task**: Tapping the `+250ml` chip on the home-screen widget now persists the intake directly via a React Native headless task (`WidgetQuickLog`) — works even when the app is fully closed. Handles double-taps and stale optimistic bumps by re-syncing from the authoritative total after every write.
- **Expanded Widget Size Support**: Added three new widget layout variants — `widget_water_large`, `widget_water_tall`, and `widget_water_tiny` — so the hydration widget scales correctly across all Android home-screen grid sizes.
- **Native Quick-Log Receiver**: Introduced `WidgetQuickLogReceiver.kt` and `WidgetQuickLogTaskService.kt` to bridge the widget tap to the JS headless task without requiring the main Activity.

### 🐛 Bug Fixes
- **Accurate Log Count on Widget**: `WidgetSync.sync()` now passes today's actual log entry count (`logsToday`) to the native layer instead of the old spend-tracking metric, so the widget subtitle reflects hydration data correctly.
- **Removed Stale Spend Sync**: Eliminated the redundant `PurchasesStorage` import and today-spend calculation from `WidgetSync.ts` — the widget is hydration-only.
- **Widget Background Drawable Cleanup**: Removed `widget_water_bg.xml` (replaced by the inline shape in each layout) to fix a rendering artifact on MIUI/One UI launchers.

### 🎨 UI Improvements
- **Ripple & Pill Drawables**: Added `widget_ripple_root.xml` and `widget_quicklog_pill_bg.xml` for a native-feeling touch ripple on the quick-log chip and a proper pill-shaped background.
- **Refreshed Widget Color Tokens**: Updated `widget_colors.xml` and `widget_colors.xml (night)` to align surface/border tints with the latest in-app glassmorphic palette.
- **Widget Resize Config**: Updated `widget_water_info.xml` to correctly declare `minResizeWidth`/`minResizeHeight` and `targetCellWidth`/`targetCellHeight` for Android 12+ adaptive sizing.
- **Config Plugin Hardening**: `withWaterWidget.js` now copies all new layout and drawable files into the generated `android/` project on `expo prebuild` and registers the new broadcast receiver + headless task service in `AndroidManifest.xml` automatically.
