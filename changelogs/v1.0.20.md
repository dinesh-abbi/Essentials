# Release Changelog v1.0.20

*Released on: Thursday, 13 August 2026*

**The "Cockpit" design overhaul.** A full design-system pass that moves the app
off the generic Tailwind-default palette onto a custom graphite instrument
panel with one signal-azure accent and a dedicated aqua tint for hydration.

### 🚀 New Features
- **Cockpit token system** (`constants/theme.ts`): a custom graphite neutral
  ramp + one signal azure (`#1F63D6` light / `#4C90FF` dark), an `aqua` water
  domain tint, semantic `success`/`warn`/`alert`, plus additive `Motion`,
  `Type`, and `Elevation` tokens. Every value is shifted off the raw Tailwind
  swatches the app used to ship.
- **Shared `<Button>` component**: 4 variants (primary / secondary / ghost /
  destructive) × 3 sizes, with real default / pressed / disabled / loading
  states, a single spring press-scale, accessible role/state, and a guaranteed
  ≥44 dp tap target even at the 36 dp size.

### 🐛 Bug Fixes
- **Reduced-motion support everywhere**: every looping animation (ambient
  blobs — now removed, water waves, rotating rings, bubbles, pulse dots,
  scanner laser, alarm bell, skeleton shimmer, count-ups) is gated on
  `useReducedMotion()`, so the app respects the OS "Reduce Motion" setting.
- **Odometer digit jitter**: home-screen numbers are now monospaced tabular
  readouts, so the count-up no longer shifts the layout.
- **Dead code removal**: dropped the ambient gradient blobs, glassmorphism
  layer, bobbing badge, and orphaned styles from the home dashboard, plus
  unused imports.

### 🎨 UI Improvements
- **Home dashboard**: de-glassed to solid graphite panels, ambient blobs
  removed, water switched to the aqua tint, spend meter changed from a rainbow
  to a semantic calm → caution → alarm ramp.
- **Navigation**: the floating tab bar's active color now matches the app
  accent (was a stray indigo), with a subtle signal-tinted active pill; tab
  springs and screen-transition timing unified to one motion convention.
- **Hydration screens**: daily / weekly / monthly views, the goal-reached
  celebration, and the report all moved onto the aqua water palette and
  graphite surfaces; the wave gauge is now a teal instrument well.
- **Purchases screens**: progress tracks, trend/award accents, and shadows
  moved onto tokens; the categorical chart palette is retained.
- **Login & Profile**: hand-rolled buttons replaced with the shared `<Button>`
  (Sign In, Continue with Google, Sign Out, Configure Settings); connected /
  registered states collapsed onto the single `success` token.

### 🔧 Build & Release
- **`publish-github.js`**: the old behaviour that deleted every release except
  the latest is disabled — previous versions and tags are now preserved so
  users can roll back and the release history stays intact.
