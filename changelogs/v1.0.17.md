# Release Changelog v1.0.17

*Released on: Tuesday, 21 July 2026*

### 🚀 New Features
- **Smart Build & Release Automation**: Upgraded `./build.sh` to preserve the last 2 compiled APKs to save repository storage space while maintaining release availability.
- **Automated Release Notes generator**: Added `scripts/prepare-changelog.js` which automatically drafts a release notes template containing git commits since the last tag.
- **Persistent Changelogs History**: Created the `changelogs/` folder to store release notes persistently without cleaning them up during build/deploy cycles.

### 🎨 UI Improvements
- **Floating Glassmorphic Tab Bar**: Switched to a custom floating tab bar with translucent styling, deep shadows, active capsule indicator, and tap scale spring animations.
- **Home Alarm Status Tile**: Integrated a motion-sensitive barcode alarm widget onto the Home dashboard with an animated ringing bell.
- **Profile Alarm Control Panel**: Replaced standard navigation row with an inline integrated `AlarmCard` featuring a Switch toggle, active status indicators, and collapsible settings.
